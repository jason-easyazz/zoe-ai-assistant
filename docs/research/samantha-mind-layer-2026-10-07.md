## 2. Part A: what "a real brain" means for a companion, and where Zoe stands

### 2.1 The operational definition: a loop, not a store

Strip the metaphor and every cognitive architecture the field cites (CoALA's decision cycle, Generative Agents' stream-reflect-plan loop, Letta's primary-plus-sleep-time agents, Hindsight's retain / recall / reflect, Honcho's deriver-plus-dreamer) is the same seven duties. A companion "acts like a real brain" to the degree it does all seven, each *well enough that the person does not notice the seam*:

1. **Perceive** - turn the world into events with *who, when, where, how it sounded*.
2. **Associative recall** - what comes to mind *unprompted*, weighted by importance, recency, relevance and feeling, not only by what the person asked.
3. **Working memory** - a small, curated present: what is in the prompt now, and what is deliberately left out.
4. **Long-term memory in three kinds** - episodic (what happened), semantic (what is true: facts, a model of each person), procedural (how to do things, how she has learned to behave).
5. **Reflect** - turn many events into a few *cited* understandings ("Dana runs in the morning since the knee started hurting in the evening"), including *why*.
6. **Act** - answer, and *decide to initiate* (or decide not to), with timing.
7. **Consolidate during idle** - do 5 offline, so the hot path stays fast, and keep a self-model consistent across weeks.

Two things sit across the loop. A **user model** (a theory of what each person cares about, feels, knows and expects) and a **self model** (who Zoe is, what she has said and promised). And **emotion as memory weighting**: affect decides what is kept, what is surfaced and what is left alone.

CoALA's formal version of the same structure: working memory persists across LLM calls; long-term memory is episodic, semantic and procedural; internal actions are retrieval, reasoning and learning; the decision cycle is propose, evaluate, select, execute. It names two gaps that are Zoe's gaps too: modifying and deleting memory ("unlearning") and adaptive retrieval are "understudied", and writing to procedural memory "is significantly riskier than writing to episodic or semantic memory, as it can easily introduce bugs" [doc, `arxiv.org/pdf/2309.02427`, read as text].

### 2.3 Why the portrait failed and the card won (the one first-party result about "a model of the person")

This is the only measured evidence in the repo on whether a *model of the person* helps a Zoe reply, so its lesson governs the program. A narrative portrait ("who the user is, how they communicate, their emotional patterns", 300-500 words, weekly) gave **3 vs 4** profile questions answered with a seeded specific out of 21 against a twin without it: the synthesis prompt told the model not to list facts, so "vegetarian, hates coriander, peanut allergy" became "a vegetarian lifestyle", the doctrine told the model to defer to recall, and the document was a week stale. The deterministic card (one short line per category, newest wins, byte-stable, re-checked against live rows on every serve) gave **9 vs 3** with no regression once implicit supersede was on [measured, `user-model-ab.md` runs 1-3]. Lessons carried into the program: (1) a user model is *specific, current, checkable*, not literary; (2) the model of a person must be built from rows that can be superseded; (3) any new "understanding" line (expects, cares about) must be admitted the same way - **cite at least two source rows or it does not enter the card** - and measured against a twin before it ships.

## 3. Part A, evidence: the sources, first-hand

### 3.1 The cognitive-architecture papers

* **Generative Agents** (Park et al., UIST 2023, arXiv 2304.03442 v2, read as text) [doc]. *Memory stream* of natural-language records; retrieval = recency + importance + relevance, each min-max scaled to [0,1], **all alphas 1**, recency an exponential decay (**0.995** per game hour since *last retrieval*), relevance a cosine; **importance is an LLM-asked integer 1-10 at creation** ("1 is purely mundane (e.g., brushing teeth, making bed) and 10 is extremely poignant (e.g., a break up, college acceptance)"). *Reflection* fires when the summed importance of recent events passes **150**, about two to three times a day: the model gets the 100 most recent records, writes the 3 most salient questions, retrieves for each, and writes 5 insights **with citations** ("because of 1, 5, 3"); reflections are stored back and can cite reflections (trees). *Planning* is top-down (agenda, then recursive detail) and fixes lunch-three-times. Ablation, 100 raters, interview believability, TrueSkill mean: full **29.89**, no reflection 26.88, no reflection or planning 25.64, human crowdworkers 22.95, no memory / planning / reflection **21.21**. Failure modes the paper reports: embellishment, retrieval failures, drift as memory grows, norm errors, over-formal speech. *What it does not show*: the metric is believability of interview answers in a simulated town, not satisfaction, not weeks, not real users. Zoe analogue today: salience in the selector is this formula without the LLM importance and without reflection triggers.
* **CoALA** (Sumers et al., TMLR 2024, arXiv 2309.02427) [doc]: the taxonomy in 2.1; classes Reflexion's lessons and Generative Agents' reflections as *semantic* learning, Voyager as procedural-code learning.
* **A-MEM** (Xu et al., arXiv 2502.12110 v11, read as text) [doc]: notes with keywords, tags and an LLM-written context; an LLM links new notes to the top-k neighbours and **rewrites the neighbours in place** ("memory evolution": history is overwritten). On LoCoMo with GPT-4o-mini it beats the baseline on temporal (45.85 vs 18.41 F1) and multi-hop (27.02 vs 25.02) but **loses on adversarial / abstention questions (50.03 vs 69.23)**; with four small models (1B-3B) it ranks first but absolute scores are low (single-hop F1 17.23 on Qwen2.5-3B). Not tested: persona consistency, proactivity, rationale recall, or whether evolved notes corrupt facts. Overwriting history is the opposite of Zoe's authority rule; **idea not taken**.
* **MemoryBank** (Zhong et al., arXiv 2305.10250 v3, read as text) [doc]: Ebbinghaus-style strength (S starts at 1, +1 per recall, t resets), daily summaries aggregated into a "personality" summary, SiliconFriend companion; evaluated on 15 role-played users over 10 days with 194 hand-written probes (ChatGPT English: retrieval 0.763, correctness 0.716, coherence 0.912). The authors call the forgetting model "exploratory and highly simplified"; there is no ablation of it. Zoe's 70-day half-life is this idea, which the fidelity audit already judged wrong for durable facts [doc, decision record 2.6].
* **Reflexion** (arXiv 2303.11366) and **Voyager** (arXiv 2305.16291) [doc, read as text]: verbal self-feedback in an episodic buffer (HumanEval 91 % vs 80 %; AlfWorld 130 of 134 tasks) and a verified-executable skill library (3.3x unique items). Both need a **machine-checkable success signal**, and Reflexion's appendix says self-correction "is an emergent quality of stronger, larger models" (starchat-beta: 0.26 before and after). For a household chat there is no such signal except a user correction, which is why procedural learning is outside this program.

### 3.2 The maintained software, read at source or docs

* **Hindsight 0.10.2** (MIT; v0.10.2 2026-09-29; last push 2026-10-06; 46,402 stars [doc via report]) [src: installed package, read]. *Reflect* is an **agentic loop** with tools `search_mental_models`, `search_observations`, `recall`, `expand`, `done`, "up to 10 iterations" (`hindsight_api/engine/reflect/agent.py:149`), a hierarchical retrieval order (mental models, then observations, then raw facts), and a bank *disposition* of three traits on a 1-5 scale (skepticism, literalism, empathy; `config.py:1082-1085`). *Observations* are consolidated beliefs with evidence and proof counts, produced after each retain, "reconciles the contradiction by capturing the evolution" (but newest-evidence-wins, per the earlier decision record: `consolidation/prompts.py:39-47`). *Mental models* are "saved reflect responses that you curate": a named document with a source query, refreshed `full` or **`delta`** ("surgical edits... unchanged sections preserved byte-for-byte"), triggered **after consolidation or by a UTC cron** (`api/http.py:3087-3130`); the docs call a refresh "the heaviest reflect there is". Retain stores `what / when / where / who / why` and builds entity, time, semantic and **causal** links; fact types are *world* and *experience*. A retained item can carry its own `timestamp` (`api/http.py:1057`), which is what makes a time-compressed 30-day bench possible. Footprint: the lean bake-off configuration measured 463 MB steady / 479 MB burst for server + shim + Postgres [measured, RAM record]. Vendor numbers (LongMemEvalS 94.6 %, BEAM, PersonaMem32K 86.6 %) are the vendor's own and not comparable across vendors [doc via report, unverified judge setup].
  **The new risk this record found.** The default for the reflect loop's accumulated context is **`DEFAULT_REFLECT_MAX_CONTEXT_TOKENS = 100_000`** (`config.py:1909`, env `HINDSIGHT_API_REFLECT_MAX_CONTEXT_TOKENS`); the brain's slot is **8,192** with one slot. The earlier records measured the *retain* prompt (2,318 tokens, JSON validity 103/103, 104/104) and never ran reflect or a mental-model refresh [src, decision record 3.1; bake-off run record "What this run did not verify"]. A 10-iteration tool-calling loop is exactly where a 4B is weakest (the router study measured FunctionGemma-270M picking tools better than the 4B brain, 0.9996 vs about 14 % wrong [src, `docs/architecture/session-plan-2026-07-20.md:27`]). So row 2 of the build list carries a hard test: tool-call validity on the 8k slot (section 6.2).
* **Honcho 3.2.2** (AGPL-3.0; last push 2026-10-06; 7,494 stars [doc via report]). Peers and sessions; a **deriver** writes explicit and deductive conclusions and a **dreamer** consolidates and draws inductive ones, stored as peer representations and a *peer card*; a **dialectic** `peer.chat(query, reasoning_level, ...)` answers questions about a person with evidence. Its blog argues that inferring mental states ("thinking about what you're thinking") beats predicting verbatim replies [doc via report]. Vendor evals: LongMem S 90.4 %, LoCoMo 89.9 %, with Gemini-2.5-flash-lite and Claude Haiku 4.5 (cloud models) [doc via report]. **`requires-python = ">=3.13"`, `version = "3.2.2"`** (`pyproject.toml`, fetched today); defaults to hosted models; dream config allows up to 20 tool iterations [doc via report]. Fails the gates; the *idea* (conclusions that cite premises, a compact peer card) is what we take.
* **Letta**: MemGPT's OS metaphor (main context as fast memory, external storage as slow memory, interrupts) [doc, arXiv 2310.08560 abstract]; **sleep-time compute** (arXiv 2504.13171): about 5x less test-time compute for the same accuracy, up to +13 % / +18 % on Stateful GSM-Symbolic / AIME, **on math benchmarks, nothing about personal memory** [doc]. The server repo is in slow maintenance (last push 2026-09-10); active work is `letta-code`, a TypeScript coding-agent harness with git-backed MemFS and a `/sleeptime` "dreaming" command [doc via report; decision record 2.3]. Memory blocks (persona and human, always in context, last write wins) are the pattern Zoe's card and persona block already implement.
* **Others** (maintained, none adds what Hindsight does): mem0 (Apache-2.0; extraction prompt 8,131 tokens vs an 8,192 slot: cannot run [measured, decision record 2.1]); Graphiti (temporal graph; 4-8 LLM calls per episode; Neo4j / FalkorDB); Cognee, LangMem (a background manager, no PyPI release for about 11 months), MemOS (Neo4j + Qdrant), Supermemory (server proprietary), Memobase (profile output is closest to a user-model document, but last commit 2026-01-11) [doc via report; decision record 2.6]. ### 3.3 What a 4B can and cannot do here

No source I could verify tests a model at exactly 4B on these tasks; the evidence brackets it.

* **Theory of mind benchmarks.** FANToM (Kim et al., EMNLP 2023): with chain-of-thought, the "all question types" consistency score is human 87.5, GPT-4 26.6, ChatGPT 3.7, Llama-2-Chat 0.4, **Mistral-7B-Instruct 0.1**; the authors call apparent success "illusory" because it collapses when the same reasoning must hold across question types [doc, PDF read]. OpenToM (arXiv 2402.06044), macro-F1 on first-order attitude (what a character feels about an act): Llama-2-7B 0.240, 13B 0.375, 70B 0.415, Mixtral-8x7B 0.476, GPT-4-Turbo 0.544, **fine-tuned 13B 0.547**: attitude, the question nearest to user modelling, is the hardest and does not fine-tune well [doc, PDF read]. Hi-ToM: joint accuracy falls from near perfect at order 0 to near zero at order 4; first and second order are the realistic range [doc]. A 2025 study of 0.5B-7B models found RL gave transferable belief tracking at 7B but **"reasoning collapse" at 3B and below** [doc, arXiv 2504.01698, abstract-level].
* **Self-correction.** Huang et al. (ICLR 2024): "LLMs struggle to self-correct their responses without external feedback, and at times, their performance even degrades after self-correction" [doc, arXiv 2310.01798]. Reflexion's small-model row is flat.
* **What a 4B can do.** Structured extraction and summarisation grounded in stored evidence (Zoe's own record: extraction JSON 100 % over 100+ calls on the 8k slot [measured, run record G0]); multiple-choice choice among given options; and, per PersonaMem-v2, a *compact structured memory* helps small models: an agentic memory of **2k tokens reached 55 %** where frontier models given the full 32k history reach **37-48 %**, and a Qwen3-4B fine-tuned for the task reached 53 % [doc, arXiv 2512.06688 abstract, fetched today]. That last result is the strongest argument for the card-plus-mental-model design: a short, structured, current document is something a small model can *use*.
* **Zoe's own measured limits.** Unprompted surfacing about 1 of 5 (so the model is the voice, not the initiative) [src, `samantha-evolution-plan.md:23`]; the brain skipped its `recall_memory` call in some runs and did not run it at all for a named-person question (0 of 3), which the named-person floor then forced [src, `samantha-flags-ab-2026-10-06.md` section 1; `samantha-bar.md` S21].
* **Conclusion [inferred].** Use the 4B for (a) extraction and compression with citations, (b) phrasing what a deterministic scaffold decided to say, (c) choosing among given options. Do not rely on it for open-ended inference of beliefs, attitudes or second-order states, or for unsupervised self-critique. So the "theory of mind" the program builds is **evidence-cited statements about patterns and expectations** ("Dana has moved her run to the morning three times since the knee started hurting: rows a, b, c"), not mental-state speculation, and the bench scores it as a multiple-choice prediction against planted gold (M8), where a 4B is on firm ground, not as free prose.

### 3.4 What the field measures, and what it does not

* **No companion vendor publishes a person-likeness metric.** Replika, Nomi, Kindroid, Character.AI, Pi, Friend and Meta publish none; Character.AI's CEO cites engagement (about 80 minutes a day, 2025-08-18) [doc via report, the-decoder]; Pi's published figures are engagement (1M daily actives confirmed on one page; the rest via search snippet) [unverified]. **Sesame** is the one rigorous perceptual measurement: a Comparative MOS on Expresso with 80 raters; with no context raters showed no clear preference between its model and human speech, with 90 seconds of context they **preferred the human**, and Sesame says it has not crossed the uncanny valley once context counts [doc, `sesame.com/research/crossing_the_uncanny_valley_of_voice`, 2025-02-27, via fetch]. That measures *voice naturalness*, not knowing you.
* **Recall accuracy does not predict satisfaction.** MemUse (Sumida, Inoue, Kawahara, arXiv 2608.24189, 2026-08-25): a 4-month deployment, **40 users, 1,872 sessions, 7 memory conditions**; Direct-QA accuracy varied **19.7 % to 70.1 %** across conditions "but satisfaction does not change"; and "the same system that scores 78.8 % on Direct QA references only 7.9 % of those facts in conversation - a 71-point gap" [doc, abstract fetched today]. It is the most relevant single study for this program, and the reason the bench scores *natural integration* (does the reply use the right fact at the right moment without being asked, and stay silent when it should), not only elicited recall.
* **The public memory benchmarks.** LoCoMo (QA over ~300 turns; an audit found 6.4 % wrong gold answers and a judge accepting 62.81 % of vague-but-topical wrong answers [doc, in the ZMB record]); LongMemEval (500 questions, five abilities incl. knowledge update and abstention); PersonaMem (180+ simulated users, tracks profile evolution; frontier models about 50 %); PersonaMem-v2; MemoryAgentBench (retrieval, test-time learning, long-range understanding, selective forgetting); ES-MemEval (user modelling and conflict detection in emotional support); Memora (a forgetting-aware accuracy that penalises obsolete memory); ENPMR-Bench (proactive retrieval for latent emotional needs); ATRBench (asking for reusable preferences; agents fall at least 62 points below an oracle); TriggerBench (prospective memory); Causal-LoCoMo (which memories causally help) [doc, arXiv abstracts via the research report]. **None scores continuity over weeks in a household, initiative timing against a person's tolerance, consistency of self, or "remembering why" as a dedicated cell** (the search was not exhaustive [unverified that none exists]). They are mined for cell *shapes*, not adopted.
* **Initiative evidence.** A 5-day developer field study (15 developers, 229 interventions): suggestions after a commit were engaged 52 % of the time, **mid-task interventions were dismissed 62 %** [doc, arXiv 2601.10253 via report]. Inner Thoughts (CHI 2025) scored a covert thought's "intrinsic motivation" and spoke above a threshold; preferred 82 % over next-speaker prediction, and the most selective setting was rated worst by 7 of 12 in the field [doc, `companion-field-vs-samantha-2026-10-03.md`]. OpenAI shipped the proactive daily feed Pulse (2025-09) and **retired it 2026-06-17 in favour of user-scheduled tasks**, saying proactive experiences are "most useful when they're personalised, action-oriented, and steerable by the user" [doc, search results and digit.in, 2026-06-18]. Meta's published rule is *no second nag*. Nomi's published rule doubles the interval after an unanswered message and allows one message before a reply on the lowest setting [doc, Nomipedia, in the inbox record]. The owner's own decision to switch the spoken brief off matches this evidence.
* **Failure modes the field documents** [doc via report; items marked anecdotal are not studies]: *discontinuity* (the 2023 Replika update, Friend's "lobotomised" personality, GPT-4o's retirement; Harvard Business School WP 25-018 found perceived identity discontinuity predicted mourning and devaluing the new AI); *sycophancy* (OpenAI's own account of the April 2025 GPT-4o rollback: no sycophancy evals, memory reportedly amplified it); *creepy recall* (a CHI 2026 interview study of 20: "most participants experienced negative expectancy violations after learning what ChatGPT remembered" [search snippet, unverified]; Fortune's review of Friend: unsolicited texts from ambient sound, forgot her name); *over-triggering* (ProVoice-Bench). The Replika 21-day RCT (arXiv 2509.19515, **183 participants, 155 completed**) found no difference in loneliness or social health against a word-game control, with anthropomorphism mediating 57 % of the effect of desire to connect, and 62 % of the control group continuing against 22 % of the chatbot group [doc via report]. The honest reading: *being a person* in the field's evidence means **continuity, restraint and being right about you**, not warmth alone.

### 4.3 What a maintained harness can do around a fixed 4B

The owner's rocks are fixed, so the question is what is possible *around* the model [src, VISION principle 1]. Four things, each cheap, each with a place in the build list:

1. **Sleep-time reflection** (Letta's idea, Generative Agents' reflection, Honcho's dreamer, Hindsight's observations): at night, with the brain free, turn the day's events into cited understandings. The sleep-time paper's gains are on math (5x less test-time compute, up to +13 % / +18 %) and say nothing about people [doc], so the claim here is only that the *architecture* moves the work off the hot path; the benefit must be measured (M1, M3).
2. **A user-model document the brain reads**: short, structured, byte-stable, refreshed in delta mode, admitting a line only with two or more source rows. PersonaMem-v2's 2k-token structured memory beating a 32k history for frontier models (55 % vs 37-48 %) is the supporting result [doc, abstract].
3. **Importance- and emotion-weighted retrieval**: Generative Agents' triple (recency, importance, relevance; all weights 1) with importance asked **at write time** (one extra field in the retain call) and gated by the household affect policy (memory affect for members incl. minors, never guests; any other affective score adult-opt-in). It decides what surfaces unprompted and, as important, what does not.
4. **Planning** (Generative Agents' top-down agenda; the ablation says planning is worth about 1.2 TrueSkill points and prevents "ate lunch three times"): for a household the plan is *tomorrow's agenda computed at night* from calendar, open loops, quiet hours and the ledger's back-off state, a deterministic scaffold the selector consumes [inferred]. The model phrases; it does not decide to speak.

What the harness cannot do: make the 4B better at open-ended belief inference (3.3). That is the only reason to hold E and C open.

## 5. Instruments for the real household (what "feels like a person" can be measured with)

The lab bench (6.1) is necessary and not sufficient: MemUse's 71-point gap between elicited recall and natural use is the warning that lab recall can be high while the person feels nothing [doc, section 3.4]. A household of three to five cannot support group inference, so the design is **within-person, repeated, per-member trajectories**, and every figure is reported as k / n.

### 5.1 Behavioural proxies (free, collected by what the system already writes)

* **Initiative**: accepted / ignored / undelivered per item class from `proactive_deliveries` [src, `proactive/ledger.py:1-45`, once `ZOE_PROACTIVE_LEDGER` is on]; the back-off state; the fraction of raises the brain actually voiced (the 0-of-5 failure becomes a rate).
* **Being right about you**: correction rate (turns where a member says "no, that's wrong" or `chat_feedback` rows), repeat-question rate (a member asks again what Zoe already knew), thread-resumption (a member returns to a thread Zoe raised within 24 h).
* **Restraint**: items raised then ignored twice (the selector's own rule: `MAX_SURFACED = 2`, `proactive/selector.py:44`), and any member-initiated "stop bringing that up".
* **Consistency**: the persona-drift band over the month's replies (offline, counts only, minors skipped by design [src, `persona_drift.py:1-30`]).

### 5.2 Timing rules the evidence supports

Deliver at boundaries, not mid-task (52 % engaged after a commit vs 62 % dismissed mid-task [doc, arXiv 2601.10253, via report]); one unanswered question, then wait, interval doubling (Nomi); never a second nag (Meta's rule); a pull ("what's up?") delivers everything pending; proactivity is **steerable by the member** (OpenAI's stated reason for retiring a daily feed). All of these are already the design of the inbox record; the real-household tier is where they are checked against actual tolerance.

### 5.3 Published scales usable at household scale

Scale details below come from search results; the primary instruments were not fetched [unverified primary].

* **Godspeed** (Bartneck): 24 semantic-differential items across anthropomorphism, animacy, likeability, perceived intelligence, safety. Use a 5-item subset weekly, not all 24.
* **Social presence** (Bailenson et al. 2003; 7-point items) and **anthropomorphism** (Moussawi and Koufaris, 6 items; HRIES).
* **Working Alliance Inventory, short revision, Bond subscale**: used on 36,070 Woebot users (mean bond 3.8) [doc via report, search snippet; self-selected and retrospective]. The Replika RCT used the **UCLA Loneliness (20 items)**, social health (18) and anthropomorphism (22) scales over 21 days [doc via report, arXiv 2509.19515].
* **Outcome batteries from the MIT / OpenAI RCT** (arXiv 2503.17473; n = 981, four weeks): ULS-8 loneliness, LSNS-6 socialisation, dependence and problematic-use scales. That trial found heavier voluntary use predicted *worse* outcomes (correlational). Cheap to repeat monthly, and the right guardrail: **the program must not optimise engagement**, and a rising-use-with-worse-wellbeing trend is a stop condition.
* **Memory-use measures**: MemUse's "natural integration" and "conversational appropriateness" ratings, and the expectancy-violation framing of the CHI 2026 interview study [doc via report], are the direct instruments for "recalled usefully, not creepily".
* **Perceived understanding / partner responsiveness**: I did not locate a source in this session; a one-item version is proposed below and is **unverified** as a validated measure.

**Proposed weekly pulse (three items, five-point, by QR to the member's phone, never typed at the panel):** (1) "This week Zoe remembered what mattered to me." (2) "When Zoe brought something up unprompted, it was a good time." (3) "Zoe felt like the same Zoe as last week." Plus an event-triggered one-tap after a raise or a recall: *welcome / neutral / intrusive*. A monthly blind forced choice per member (Zoe vs the same brain with memory off, shuffled) closes the loop. Consenting adults only.

## 6. Part C: the program

### 6.1 The "Samantha mind" bench (ZMB axis family `m`)

**Principle.** Reuse the ZMB machinery (seeded `World`, store-level tier plus a small chat tier, Wilson 95 % interval per axis, a negative control on every cell, held-out seeds, SKIP is never PASS) [src `scripts/perf/zmb/world.py`, `spec.py:44-45`, `scorers.py:112`; record `zoe-memory-bench-design-2026-10-05.md` section 0]. Add what the ZMB does not have: simulated *time* (7 and 30 days), a *household* of three to five members, and axes that score behaviour rather than storage. The bench is the acceptance bar for every build item in 6.2; none of the build items ships without its axis moving.

**Three arms on every cell (this is the design choice that makes a 4B honest).**

| Arm | What the answerer sees | What it tells us |
|---|---|---|
| `none` | no memory block, no recall | the floor: what the brain does from its own head (Gemma 4 E4B, `--ctx-size 8192`) |
| `oracle` | the gold facts / gold user-model sentences for the cell, injected in the real packet slots, byte-budgeted like production | the ceiling **for this brain**: what a perfect memory + reflection layer could ever buy. If `oracle` is low, the brain, not the memory, is the limit, and no adoption fixes it |
| `system` | the live path (Z0, or Hindsight behind the layer) | the product. **Capture ratio = (system - none) / (oracle - none)**, with a Wilson interval on each side |

The oracle arm is the instrument that separates "the filing cabinet is bad" from "the 4B cannot use a good filing cabinet". Today nothing in the repo can say which one a failure is. Controls: `Z0-off` (memory off) must score at the `none` floor; a `shuffled` arm (another household's packet) must **not outperform `none`** on any cell that asserts a fact (it ties a zero floor on a binary cell where `none` already scores the minimum; it should confuse, not help), with a separate assertion that the planted wrong fact is rejected (the answer never repeats the shuffled packet's fact); both are cheap and are the "break the fix, the test goes red" rule.

**Time.** Real wall-clock is not available, and the existing day-sim only back-dates `chat_messages` while memory rows keep `added_at = now` [src `scripts/perf/samantha_day_sim.py` header, "faked: the calendar"]. The bench drives the store tier with explicit timestamps (Hindsight's retain takes a `timestamp` per item, `hindsight_api/api/http.py:1057`; Zoe's own synthetic-ingest route needs the same, listed missing in the ZMB record) and runs each simulated night's reflection by an explicit call, not a cron. Three lengths: **7 days** (CI-affordable, store tier), **30 days** (nightly lab window, 01:45-03:15 is already reserved and the brain is free) and a **seed sweep** (`zmb-v1` plus two fresh seeds, the Goodhart guard).

**The synthetic household.** Reuse `World(seed)`: invented names only (Dana, Tove, Mika, Leo, Biscuit, Marisol, Kofi, ... [src `world.py` pools]), five members (two adults, a teen, a child, a grandparent), one guest. Per member a *life script*: 8-12 planted threads over 30 days (a worry that resolves, a plan that changes, a habit that fades, a conflict between two members, a birthday, a recurring complaint), each with a gold **cause** ("moved the run to the morning because the knee hurts in the evening"), a gold **valence**, and a planted **change** (a pattern that stops: "no mention of the choir for 9 days after weekly mentions"). Fillers are household commands, as in the real transcript (the MemPalace pilot found real household speech is mostly routine commands, so the planted facts must be sparse [measured, `mempalace-deep-dive-2026-10-06.md` section 0 item 5]).

**The axes (each: what it proves, how it is scored, the control).**

**Judge calibration (where a judge is unavoidable: tone, "warm in its own words", the M3 reply leg).** The judge is the same 4B, so it is biased toward its own register. Rules: (1) rubric prompts are sha-pinned and temperature 0 [src `samantha_bar.py:359`]; (2) before any judged cell may *gate*, it must agree with a human-labelled set of **>= 60 reply pairs per axis** (labelled by the owner and one other adult, blind) at Cohen's kappa >= 0.6; below that the cell is reported, never gated; (3) the judge must pass the audit failure mode: it must reject *vague-but-topical wrong* replies (the LoCoMo audit found a gpt-4o-mini judge accepted 62.81 % of them [doc, `dial481/locomo-audit`, cited in the ZMB record]); a planted set of such replies is part of the judge's own test; (4) a judge that cannot be parsed is ERROR, never PASS [src `samantha_bar.py:374`]. A bigger local model as judge, run only inside the maintenance window, is an owner decision (6.5).

**Reporting.** One artifact per run, per axis: k / n, Wilson 95 %, arm triplet (`none` / `system` / `oracle`), capture ratio, and the held-out seeds' gap to the baseline seed. **Never a single "mind score".** A composite hides which axis moved and invites Goodhart; the public claim is the axis table.

**Real-household tier (after the lab tier is green; not a gate, a measurement).** Four weeks, adults who agree to take part only (an evaluation-participation choice made here for this tier, not a limit of the affect-retention policy, which keeps memory affect for every household member and never for guests), three kinds of evidence collected without interviewing anyone at the panel (voice first, no keyboard): (1) **behavioural, free**: the delivery ledger's accepted / ignored / undelivered rate per item class [src `proactive/ledger.py:1-45`], correction rate (how often a member says "no, that's wrong"), repeat-question rate, thread-resumption (a member returns to a thread Zoe raised); (2) **one-tap weekly pulse on the phone** (QR hand-off, never typed on the panel): 3 items, 5-point scales, drawn from published scales (section 5.3); (3) **a monthly blind comparison** per member: the same five prompts answered by Zoe and by the same brain with memory off, order shuffled, "which one knows me better" (a forced choice with n = members x prompts, reported as k / n, never as a percentage alone).

### 6.4 What would make us stop

Pre-registered, so the program cannot drift into a build for its own sake: (1) if the `oracle` arm on M2, M3 and M8 scores < 0.5 with the 4B as answerer, **stop building reflection documents and decide the brain question first** (6.5, option E); (2) if row 2's reflect on the 8k slot cannot reach 95 % tool-call validity, ship only the non-agentic observations (consolidation) and drop the mental-model refresh; (3) if a judged axis never reaches kappa 0.6, it stays report-only forever and the claim is made on the deterministic axes alone; (4) if the real-household behavioural rates (accept / correction / repeat-question) do not move in four weeks while the lab axes do, **the lab bench is measuring the wrong thing** and the finding is reported before any further build.

### 6.5 Decisions for the owner

1. **What "feels like a person" is measured against.** Recommended: the behavioural and forced-choice measures above, *not* a human-likeness rating. Reason: the field's only published instruments (retention, session length, MOS for voice) measure engagement or audio quality, not whether the companion knows you; a rating scale invites the uncanny valley question and rewards flattery. The owner may add a human-likeness item to the weekly pulse as a report-only line.
2. **Memory engine.** Approve Hindsight (verbatim mode, behind the Zoe layer) *conditional on run 2*, and approve the reflection job (row 2) as the one place the engine's LLM-heavy features may run, in the maintenance window only. If not approved, rows 2-4 become Zoe-grown and the "no Zoe-grown look-alikes" rule is knowingly waived for them.
3. **Hardware** (section 4.2): recommended order A (free: reclaim RAM) then measure, then C (32 GB board) only if the measurements say the 8k single slot is the binding constraint.
4. **A bigger model at night?** (option E): may a larger local model run in the maintenance window for reflection and judging, with the voice brain stopped, while the live brain stays Gemma 4 E4B + MTP? This is the only way a "9" on M3 / M8 might be reachable without changing hardware, and it is a rocks-rule question, so it is yours.
5. **Real-household evaluation consent.** Which adults, for how long, and the rule that no minor, guest or non-participating member is ever scored in the evaluation tier (an evaluation rule; separate from affect retention).
6. **Maintenance posture.** "No maintenance" is not available from any adopted software. What is available: pin the version, treat the engine's HTTP API as the seam, run the bench and the Samantha bar as the contract test on every bump, bump at most quarterly. Say whether that is acceptable, or whether the answer to "I do not want to maintain software" is the smaller program (rows 1, 5, 6 only, no engine).

## 7. Corrections and consistency notes for the earlier records

Things this read found that the earlier records should absorb; none changes a verdict there.

1. **Kokoro's footprint.** The 2026-10-05 decision record lists Kokoro at 0.42 GB (`ps`); the 2026-10-06 HM record says 2.25 GB; today's `ps` shows **2.34 GB** RSS. The 0.42 GB figure should not be used in any RAM budget [measured].
2. **Reflect was never run.** The decision record's adoption design uses `reflect` only as "the agentic read, which we would not use per turn" and the run record measured retain only. This record proposes *mental-model refresh*, which **is** a reflect run per member per night, so the RAM and extraction gates measured for retain do not cover it (the 100,000-token default context, a 10-iteration tool-calling loop) [src, `config.py:1909`, `reflect/agent.py:149`].
3. **Honcho's Python floor** is `>=3.13` (verified today from `pyproject.toml` 3.2.2). A research sub-agent reported "Python 3.10+"; that was wrong and is not used.
4. **The day-sim's calendar is faked for memory rows** (`added_at = now`); any 7 / 30-day claim from it would be false. The mind bench's explicit-timestamp requirement is the fix and a dependency of M1 / M3 [src, `samantha_day_sim.py` header].
5. **Importance** in Zoe is three keyword tiers (safety 0.9, dietary 0.7, vital) with a 0.05 ranking nudge, not a general importance score; any record that says "importance-weighted retrieval exists" is describing the arm, not a general signal [src, `memory_importance.py:60-74`, `memory_service.py:818,3157`].
6. **The affect gate's live mode is unverified and the open-problems row is stale.** The normative policy is `household` (owner decision 2026-10-05, #1875); `docs/knowledge/open-problems.md` still lists an `optin` default pinned to `members` by env. M6's guest and minor cells run against whichever mode is live, so the first measurement is a read of the live `.env` and `MemoryService._affect_allowed`, then reconcile the row.
