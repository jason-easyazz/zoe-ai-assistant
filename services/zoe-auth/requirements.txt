# ── DEFERRED: fastapi 0.125.0 -> 0.141.1 + pydantic 2.5.0 -> 2.13.4 ───────────
# These two must move together (fastapi 0.141.1 requires pydantic>=2.9.0, and
# pydantic 2.13.4 requires typing-extensions>=4.14.1 — already bumped above), but
# the pair was held back out of this currency sweep because it is a behavioural
# change to a LIVE auth service, not a routine bump:
#   * FastAPI 0.132.0 made `strict_content_type` default TRUE — JSON requests
#     without a valid `Content-Type` header are now REJECTED. The browser UI does
#     send it (services/zoe-ui/dist/js/auth.js), but the Pi daemon, panel and
#     internal service callers have not been audited.
#   * fastapi 0.141.1 drops its `starlette<0.51` ceiling, so it resolves Starlette
#     1.x — a major jump that removes `@app.route`, `@app.on_event`,
#     `add_event_handler` and the old Jinja2Templates signatures. FastAPI shims
#     the ones it owns; direct Starlette imports are not shielded.
#   * pydantic 2.9.0 switched `Field(pattern=...)` from `re.match` to `re.search`,
#     silently loosening any unanchored pattern (this file's callers use several),
#     and 2.8.0 changed smart-union matching.
# Do it as its own PR: audit every non-browser client for Content-Type, grep for
# direct `starlette` imports, and anchor the `pattern=` constraints first.
